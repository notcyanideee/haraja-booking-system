# Booking Management System

A full-stack web application for managing customer bookings and reservations.

## Live Website

http://haraja.infinityfree.me 

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Features

- User registration and login
- Customer booking system
- Booking management
- CRUD functionality
- User management
- Admin dashboard
- Database integration
- Booking validation

## About

This project was created as a full-stack booking system with separate
functionality for customers and administrators. It was developed to
practice back-end development, database management, authentication,
CRUD operations, and web application design.
